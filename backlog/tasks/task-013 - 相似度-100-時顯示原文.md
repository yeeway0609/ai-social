## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
使用者指出如果 AI 修改後和原版的語意相似度是 100%，代表沒有實質改寫，畫面應直接顯示原文，不需要提示 AI 改過。現行快取與生成成功路徑會把所有成功結果標為 AI 改寫，需要調整後端回傳契約。
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 生成結果語意相似度等同 100% 時回傳原文並標為 isOriginal: true
- [x] #2 相似度 100% 的結果不寫入預設語氣改寫快取，避免之後命中快取仍顯示 AI 改寫
- [x] #3 既有快取若帶有 100% 語意相似度，讀取時也回傳原文而非 AI 改寫
- [x] #4 相關文件、測試與格式檢查通過
<!-- AC:END -->

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. 新增語意相似度等同 100% 的判斷工具，處理浮點數近似值。

2. 調整 renderContent()：生成或快取命中 100% 相似度時回傳正式原文、isOriginal: true，且不寫入新快取。

3. 更新 PRD／契約文件與測試，確認前端會自然顯示原文標籤。
<!-- SECTION:PLAN:END -->
